# SAS Macros

Reusable SAS macros developed for the CONZUL Copyright Dashboard project.

## Included Macros

### inputfiles
Imports Excel datasets into SAS datasets.

### material_maj
Standardises publication material categories and cleans text fields.

### NZ_pub_step1
Creates publication country and city variables from publication location data.

### NZ_pub_step2
Identifies New Zealand publishers and university presses using keyword matching.

## Purpose

These macros reduced repetitive code and created a consistent processing workflow across multiple university datasets.
