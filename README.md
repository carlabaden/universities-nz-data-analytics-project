# CONZUL Copyright Dashboard (2019–2024)

## Data Analyst Internship | Universities New Zealand

### Overview

During my Data Analyst internship with **Universities New Zealand**, I worked on a project for the **Council of Aotearoa New Zealand University Libraries (CONZUL)** to update the CONZUL Copyright Dashboard with 2023 and 2024 data.

The dashboard combines copyright usage data from all eight New Zealand universities and supports CONZUL in copyright licensing negotiations with publishers. I contributed to the data preparation, validation, and dashboard development process using Excel, SAS, and Tableau.

---

## Project Objectives

- Update the existing dashboard with 2023 and 2024 data.
- Clean and standardise data from eight New Zealand universities.
- Ensure data quality and consistency across multiple reporting years.
- Develop an interactive dashboard that met stakeholder requirements.
- Present updates and implement stakeholder feedback.

---

## My Role

My responsibilities included:

- Cleaning and standardising large datasets in Microsoft Excel.
